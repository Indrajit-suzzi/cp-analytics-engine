# Competitive Programming Analytics Engine

A backend analytics system that integrates with Codeforces API to analyze user performance, topic strengths, and rating trends.

## Features
- Fetch user data from Codeforces
- Topic-wise strength detection
- Strongest & weakest topic analysis
- Contest participation tracking

## Tech Stack
- Node.js
- Express.js
- Axios
- REST API

## Future Improvements
- Rating growth prediction model
- Topic difficulty heatmap
- React dashboard
- MongoDB integration
